# Лабораторна робота: Git та Юніт-тестування

Проєкт реалізує алгоритм Штрассена для множення комплексних матриць на C++.

Мета роботи — покрити існуючий код юніт-тестами та продемонструвати повний цикл розробки з Git/GitHub, включаючи роботу з гілками та Pull Requests.

---

###  Технології

* **Мова:** C++17
* **Система збірки:** CMake
* **Фреймворк тестування:** GoogleTest (gtest)

---

###  Структура проєкту

* `src/`: Вихідний код реалізації (класи `Complex`, `Matrix` та логіка `Strassen`).
* `tests/`: Юніт-тести для всіх компонентів проєкту.
* `CMakeLists.txt`: Файл для конфігурації збірки та автоматичного підключення GoogleTest через `FetchContent`.

---

###  Стратегія тестування

Проєкт покрито **24 юніт-тестами**, які перевіряють різні аспекти коду:

1.  **Клас `Complex`**:
    * Коректність базових арифметичних операцій.
    * Обробка граничних випадків при порівнянні чисел з плаваючою комою (з використанням `EPSILON`).

2.  **Клас `Matrix`**:
    * Коректність базових операцій (додавання, доступ до елементів).
    * **Обробка винятків**: Перевірка, що програма коректно генерує помилки при спробі доступу за межі матриці (`std::out_of_range`) або при операціях з матрицями несумісних розмірів (`std::invalid_argument`).

3.  **Алгоритм `Strassen`**:
    * **Коректність результату**: Порівняння результату з класичним алгоритмом множення для матриць різних розмірів (`2x2`, `4x4`).
    * **Граничні випадки**: Тестування матриць, розмір яких не є степенем двійки (`3x3`), а також прямокутних матриць, що перевіряє логіку `padding` та `unpadding`.

4.  **Допоміжні функції**:
    * Тестування хелперів (`nextPowerOfTwo`, `split`/`combine`) за допомогою параметризованих тестів.

---

### Збірка та запуск

**Вимоги:** CMake (версії 3.14+) та C++ компілятор.

1.  **Конфігурація проєкту:**
    ```bash
    cmake -B build
    ```
2.  **Збірка:**
    ```bash
    cmake --build build
    ```
3.  **Запуск основної програми:**
    ```bash
    ./build/main # Linux/macOS
    .\build\main.exe # Windows
    ```
4.  **Запуск тестів:**
    ```bash
    ./build/run_tests # Linux/macOS
    .\build\run_tests.exe # Windows
    ```
